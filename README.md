# IELTS AI Preparation Platform

A professional, interactive, AI-powered platform for IELTS Academic students to practice Listening, Reading, Writing, and Speaking with instant feedback and band score estimation.

## 🚀 MVP Features
* **Dashboard:** Track progress, estimated band scores, and weak areas.
* **Listening:** Audio player with multiple question types.
* **Reading:** Side-by-side passage and question interface with timers.
* **Writing:** Task 1 & Task 2 text editors with live word counts and AI evaluation.
* **Speaking:** Voice recording interface with simulated examiner prompts.

## 🛠 Technology Stack
* **Frontend:** Streamlit (Python)
* **AI Provider:** Grok API
